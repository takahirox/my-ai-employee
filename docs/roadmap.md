# Roadmap

## v0.2 (implemented vertical slice)

- Codex/Claude Code strict proposal adapters and controlled edit proposals.
- Process/download/project-local install mediation with explicit policy and approval.
- Git worktree isolation, deterministic verification, evidence inspection, and
  explicit exact-digest patch promotion.
- Project Harness v2 plus safe v1 migration/provisional discovery.

## v0.3 (planned, not implemented)

- Container-backed execution profiles.
- Distributed scheduling and durable coordination.
- Multi-host observability and operator approval workflows.
- Carefully bounded improvement proposals with independent review.

These items are directional. v0.2 remains single-machine and local-first; it does not
implement containers, distributed execution, deployment, automatic publication, or
autonomous Runtime self-modification.

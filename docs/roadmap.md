# Roadmap

## v0.2 (planned, not implemented)

- Optional provider adapters behind the existing typed handler boundary.
- Stronger subprocess permission mediation and sandbox integration.
- Richer Inspector filtering and evidence navigation.
- Additional Project Harness validation and migration tooling.

## v0.3 (planned, not implemented)

- Container-backed execution profiles.
- Distributed scheduling and durable coordination.
- Multi-host observability and operator approval workflows.
- Carefully bounded improvement proposals with independent review.

These items are directional. v0.1 remains a deterministic, single-process, offline trust
kernel; it does not implement provider calls, containers, distributed execution, or autonomous
self-improvement.

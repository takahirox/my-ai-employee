# Security policy

Use the repository's **Security** tab and **Report a vulnerability** to open a
private GitHub security advisory. If private reporting is unavailable, open a public
issue containing no vulnerability details and ask for a private contact channel.
Never include live credentials or sensitive user data in a public report.

The maintained runtime is described in [docs/security.md](docs/security.md).
Version 0.3 replaces the old proposal runtime and does not migrate legacy history.
